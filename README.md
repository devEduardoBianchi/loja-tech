# FIO / tech

Loja conceitual de eletrônicos e informática para portfólio. Produtos, especificações e valores são fictícios. Não há venda, checkout, cadastro, pagamento ou integração externa.

## Executar

```bash
npm install
npm run dev
```

Abra o endereço mostrado pelo Vite. Para validar: `npm run build`, `npm run lint` e `npm test`.

O catálogo, favoritos, comparação e carrinho demonstrativo usam dados locais. Favoritos, comparação e carrinho são guardados no armazenamento deste navegador; nenhuma informação pessoal é solicitada.

No catálogo, a lente de leitura destaca dados já presentes nas fichas, sem alterar a ordenação. Na comparação, é possível dar foco a um critério mantendo todas as linhas disponíveis. O questionário conduz rotina, prioridade e investimento em três etapas e explica a pontuação usada na sugestão, sem IA. As imagens, produtos, especificações e valores são fictícios.

O banner inicial usa imagens próprias para desktop e celular. Texto e botões continuam em HTML sobre a fotografia. A direção visual está descrita em `docs/fio-de-luz.md`.
